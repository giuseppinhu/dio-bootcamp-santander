O que é a tag <'p'> no HTML?

A tag <'p'> no HTML é usada para definir um parágrafo de texto em uma página web. A letra “p”.2 vem da palavra paragraph (parágrafo, em inglês). Essa tag é uma das mais básicas e importantes no HTML, utilizada para organizar e estruturar o conteúdo textual.

Sintaxe:

'p'>Este é um parágrafo de exemplo.<'/p'>
figura .1<

Principais Características

  1. Todo o conteúdo dentro da tag <'p'> será exibido como um bloco de texto separado dos outros elementos.
  2. Por padrão, os navegadores aplicam uma margem antes e depois do parágrafo para dar espaçamento entre os blocos de texto.
  3. A tag <'p'> deve ser usada para textos completos ou frases. Não é recomendável usá-la apenas para palavras soltas ou títulos.

Exemplo do uso da tag.

<'p'>HTML é a linguagem usada para criar páginas na web.<'/p'>
<'p'>Com ela, podemos estruturar textos, imagens, links e muito mais.<'/p'>
